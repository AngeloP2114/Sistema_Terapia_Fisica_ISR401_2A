# Scripts de análisis

## Instalación

```bash
python -m pip install -r requirements.txt
```

## Ejecución

Desde `06_Experimento/`:

```bash
python scripts_analisis/analisis_explicabilidad.py
```

El script lee `resultados/respuestas_anonimizadas.csv` o, si todavía no existe, informa que primero debe completarse la plantilla.
