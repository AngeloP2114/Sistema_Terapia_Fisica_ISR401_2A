# Resultados del componente experimental

Esta carpeta contiene los datos y resultados derivados del componente empírico del proyecto SICST.

Los resultados se generan a partir de entrevistas, cuestionarios, walkthrough, codificación temática y análisis de requisitos de explicabilidad.

## Archivos esperados

- datos_crudos_cuestionario.csv
- datos_procesados_cuestionario.csv
- tabla_resultados_cuestionario.xlsx
- resultados_walkthrough.csv
- resultados_explicabilidad.csv
- figura_resultados_cuestionario.png
- figura_resultados_walkthrough.png
- curva_saturacion.png

## Descripción

Los datos crudos corresponden a las respuestas originales recolectadas durante el trabajo de campo.

Los datos procesados corresponden a tablas limpias y organizadas para análisis.

Las figuras permiten representar los resultados del cuestionario, validación walkthrough y curva de saturación temática.
