# Rúbrica de Evaluación de Calidad de Requisitos SICST

## Objetivo

Esta rúbrica permite evaluar la calidad de los requisitos funcionales del Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST).

La evaluación considera características de calidad relacionadas con la ingeniería de requisitos.

Cada criterio será evaluado mediante una escala binaria:

- 1 = Cumple el criterio.
- 0 = No cumple el criterio.

---

# Criterios de evaluación

## 1. Claridad

Evalúa si el requisito está redactado de manera comprensible, sin ambigüedades y utilizando un lenguaje preciso.

### Cumple (1)

El requisito tiene una redacción clara y permite comprender la funcionalidad esperada.

### No cumple (0)

El requisito presenta ambigüedad, términos confusos o dificultad para interpretar su intención.

---

## 2. Completitud

Evalúa si el requisito contiene la información necesaria para describir la funcionalidad.

### Cumple (1)

El requisito define claramente qué debe realizar el sistema.

### No cumple (0)

El requisito presenta información insuficiente o incompleta.

---

## 3. Verificabilidad

Evalúa si es posible comprobar mediante una prueba si el requisito fue implementado correctamente.

### Cumple (1)

El requisito permite definir una prueba o criterio de aceptación.

### No cumple (0)

No existe una forma clara de comprobar su cumplimiento.

---

## 4. Trazabilidad

Evalúa la relación del requisito con otros artefactos del proyecto.

Ejemplos:

- Casos de uso.
- Modelos.
- Historias de usuario.
- Diseño del sistema.

### Cumple (1)

El requisito tiene relación con otros elementos documentados.

### No cumple (0)

El requisito no tiene evidencia de seguimiento.

---

## 5. Consistencia

Evalúa que el requisito no presente contradicciones con otros requisitos del sistema.

### Cumple (1)

El requisito mantiene coherencia con la especificación completa.

### No cumple (0)

El requisito contradice otro requisito o presenta conflictos.

---

# Registro de evaluación

Los resultados serán almacenados en:

datos/evaluacion_experta.csv


Cada requisito será evaluado utilizando los cinco criterios definidos.

---

# Participantes de evaluación

La evaluación será realizada mediante revisión experta del documento ERS/SRS del SICST.
