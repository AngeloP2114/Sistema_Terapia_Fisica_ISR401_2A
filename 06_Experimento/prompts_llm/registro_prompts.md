# Registro transparente de uso de modelos de lenguaje (LLM)

## Proyecto

**Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**

**Asignatura:** Ingeniería de Requerimientos — ISR-401

**Repositorio:** AngeloP2114/Sistema_Terapia_Fisica_ISR401_2A

## Propósito del registro

Este documento registra usos reales de modelos de lenguaje durante el
desarrollo, documentación, revisión y preparación académica del proyecto SICST.

Los modelos de lenguaje se utilizaron como herramientas de apoyo para tareas
de revisión documental, estructuración, redacción, preparación de material
técnico y auditoría del repositorio.

No se utilizan modelos de lenguaje para fabricar participantes, entrevistas,
consentimientos, observaciones de campo, resultados experimentales,
aprobaciones institucionales ni cualquier otra evidencia que no haya ocurrido
realmente.

Cuando la interfaz utilizada no proporciona valores técnicos como temperatura,
top-p o semilla, estos parámetros se registran como "No disponible".

- revisión de privacidad;
- revisión de CITATION.cff y CHANGELOG.

Estas actividades forman parte del historial real del proyecto. Sin embargo,
cuando el texto literal completo de una consigna anterior no puede recuperarse,
no se incorpora artificialmente como "prompt exacto" en la tabla.

# Uso de LLM durante el experimento

El experimento correspondiente a la comparación entre elicitación humana y
requisitos generados mediante LLM deberá registrarse por separado cuando sea
ejecutado realmente.

Cada ejecución experimental deberá registrar como mínimo:

- fecha y hora de ejecución;
- modelo utilizado;
- versión del modelo, cuando esté disponible;
- transcripción anonimizada utilizada como entrada;
- prompt exacto;
- salida completa obtenida;
- persona responsable de ejecutar la prueba;
- revisión humana de la salida;
- criterios utilizados para evaluar los requisitos resultantes.

No se incorporan a este registro ejecuciones experimentales que todavía no
hayan ocurrido.

---

# Principios de integridad

1. No se fabrican prompts históricos que no puedan recuperarse.
2. No se inventan parámetros técnicos no proporcionados por la plataforma.
3. No se generan respuestas ficticias de participantes.
4. No se utilizan LLM para crear entrevistas inexistentes.
5. No se fabrican resultados experimentales.
6. No se presentan aprobaciones institucionales inexistentes.
7. Las salidas generadas por LLM son revisadas por personas antes de
   incorporarse a los artefactos del proyecto.
8. Los resultados empíricos deben permanecer vinculados a evidencia primaria.
