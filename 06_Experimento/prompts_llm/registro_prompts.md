# Registro de uso de LLM

Los modelos de lenguaje no se utilizarán para generar respuestas de participantes, resultados, evidencias ni conclusiones empíricas.

Cuando se utilicen únicamente como apoyo de redacción, se registrará:

| Fecha | Modelo y versión | Temperatura | Top-p | Semilla | Consigna exacta | Uso de la salida | Revisión humana |
|---|---|---:|---:|---:|---|---|---|
| | | | | | | | |

Toda afirmación sustantiva debe mantenerse vinculada con evidencia primaria o bibliografía verificable.
