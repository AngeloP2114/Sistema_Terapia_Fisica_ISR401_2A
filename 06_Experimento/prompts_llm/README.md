# Prompts LLM

Esta carpeta se reserva para documentar consignas utilizadas con modelos grandes de lenguaje, en caso de que se apliquen dentro del componente experimental.

## Alcance en este proyecto

El proyecto SICST selecciona el Enfoque 3: elicitación y validación de requisitos de explicabilidad para el componente inteligente del sistema.

Por este motivo, no se utilizan prompts LLM para generar resultados experimentales, requisitos ni interpretaciones. El análisis se sustenta en entrevistas, cuestionarios, walkthrough, codificación temática y evidencias de campo.

## Uso permitido

En caso de emplearse un LLM únicamente como apoyo de redacción o traducción, se documentará:

- Fecha de uso.
- Modelo utilizado.
- Prompt aplicado.
- Propósito del uso.
- Fragmento asistido.
- Evidencia primaria que respalda el contenido redactado.

## Regla de evidencia

Ningún requisito, resultado o interpretación se declara sin respaldo empírico verificable dentro del repositorio.
