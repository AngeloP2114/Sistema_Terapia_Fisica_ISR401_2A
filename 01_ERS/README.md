# ERS/SRS final — SICST PE5

Esta carpeta contiene la línea base final del documento de Especificación de Requisitos de Software del proyecto **Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**.

## Archivos principales

- `ERS_SRS_SICST_PE5_FINAL1.pdf` — versión final en PDF.
- `ERS_SRS_SICST_PE5_FINAL1.docx` — versión editable en Word.
- `main.tex` — archivo fuente principal en LaTeX.
- `assets/` — recursos gráficos requeridos para la compilación.
- `LEEME_OVERLEAF.txt` — instrucciones adicionales para compilación en Overleaf.

## Compilación del ERS/SRS

El código fuente del ERS/SRS utiliza **pdfLaTeX**.

Desde la carpeta `01_ERS/` puede ejecutarse:

```bash
pdflatex main.tex
