PROYECTO LATEX ERS/SRS SICST PE5
================================

Este proyecto reconstruye el documento ERS/SRS de 180 paginas como codigo
LaTeX autentico. No inserta el PDF original como contenido.

ARCHIVOS
--------
- main.tex: codigo principal editable.
- assets/: 60 fotografias, capturas y diagramas procedentes del Word.

COMO ABRIRLO EN OVERLEAF
------------------------
1. No descomprima el ZIP antes de subirlo.
2. En Overleaf seleccione New Project > Upload Project.
3. Suba el archivo ZIP completo.
4. Verifique que el documento principal sea main.tex.
5. En File > Settings > Compiler seleccione pdfLaTeX.
6. Presione Recompile.

IMPORTANTE
----------
La carpeta assets no debe eliminarse. Este documento contiene 60 evidencias
fotograficas, capturas y diagramas; por esa razon, para conservar el mismo
diseno, el proyecto necesita esos archivos internos. El ZIP permite subirlo
como un solo archivo y Overleaf organiza automaticamente el proyecto.

VERIFICACION
------------
- Compilador: pdfLaTeX.
- Paginas generadas: 180.
- Paginas horizontales: 106 a 109.
- No requiere XeLaTeX ni fuentes externas.
