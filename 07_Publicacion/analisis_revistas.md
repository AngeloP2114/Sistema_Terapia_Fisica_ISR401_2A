# Análisis de revistas objetivo

**Fecha de consulta:** 2 de agosto de 2026.

## 1. IEEE Access - alternativa de acceso abierto con APC

- **Editorial:** IEEE.
- **Modelo:** acceso abierto dorado; el artículo queda disponible para todos los lectores.
- **APC oficial consultado:** USD 2,160 más impuestos locales aplicables.
- **Ajuste temático:** admite trabajos de ingeniería, informática, sistemas inteligentes y validación de soluciones tecnológicas.
- **Ventaja para SICST:** alcance multidisciplinario adecuado para integrar ingeniería de requisitos, IA explicable y seguimiento de rehabilitación.
- **Riesgo:** el APC requiere financiamiento y el manuscrito debe demostrar aportación técnica y evaluación empírica sólida.
- **Fuente oficial:** https://ieeeaccess.ieee.org/about/article-processing-charges/

## 2. Requirements Engineering - alternativa híbrida/suscripción sin APC obligatorio

- **Editorial:** Springer Nature.
- **Modelo:** revista híbrida. La publicación tradicional por suscripción no obliga al autor a pagar un APC; el acceso abierto es opcional.
- **APC opcional de acceso abierto consultado:** USD 3,090 / EUR 2,490 / GBP 2,190, sujeto a impuestos.
- **Ajuste temático:** se centra en elicitación, representación, validación y gestión de requisitos de sistemas intensivos en software.
- **Ventaja para SICST:** es la opción con mayor alineación temática para un artículo centrado en evidencia empírica, trazabilidad, explicabilidad y validación de requisitos.
- **Riesgo:** exige una contribución científica clara y una metodología rigurosa; el trabajo debe superar la descripción de un proyecto académico.
- **Fuente oficial:** https://link.springer.com/journal/766/how-to-publish-with-us

## Comparación y selección preliminar

| Criterio | IEEE Access | Requirements Engineering |
|---|---|---|
| Modalidad principal | Acceso abierto con APC | Híbrida/suscripción; OA opcional |
| APC obligatorio | Sí | No en la ruta tradicional |
| Alineación con requisitos | Media-alta | Muy alta |
| Alineación con IA y salud digital | Alta | Media-alta si el aporte central es RE |
| Recomendación | Alternativa cuando exista financiamiento | Revista objetivo prioritaria por pertinencia temática |

## Decisión propuesta

La revista objetivo prioritaria es **Requirements Engineering**, utilizando inicialmente la ruta tradicional por suscripción para evitar un cargo obligatorio. **IEEE Access** se conserva como alternativa de acceso abierto si el equipo obtiene financiamiento institucional y amplía la evaluación técnica del sistema.
