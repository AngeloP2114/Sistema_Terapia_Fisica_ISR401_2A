## Datos actuales

El conjunto reproducible actual contiene **79 respuestas codificadas**:

- 62 pacientes o ex pacientes de terapia física;
- 14 familiares o cuidadores;
- 3 fisioterapeutas.

La fuente reproducible vigente se encuentra en:

`../../07_Datos/`

## Reproducción

Desde la raíz del repositorio ejecutar:

`python 07_Datos/scripts/orquestar.py`

El script genera los datos procesados, el resumen de perfiles y los checksums SHA-256.

## Integridad

Los hashes de los archivos de datos se encuentran en:

`../../07_Datos/checksums_datos.sha256`

## Privacidad

El paquete reproducible no incluye nombres completos, cédulas, teléfonos, firmas ni consentimientos firmados.

Los códigos de participante se conservan para trazabilidad académica y no deben utilizarse para intentar identificar o reidentificar personas.
