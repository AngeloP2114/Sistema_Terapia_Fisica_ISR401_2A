# Publicación — SICST PE5

Esta carpeta reúne los artefactos de preparación de publicación académica del proyecto **Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**.

## Contenido

- `manuscrito_borrador.pdf`: borrador de artículo científico.
- `analisis_revistas.md`: análisis preliminar de revistas objetivo.
- `dataset_zenodo/`: paquete anonimizado preparado para un posible depósito posterior en Zenodo.

## Línea base final PE5

El informe final oficial de PE5 se mantiene en:

`PE5_Informe_Final/`

La matriz de trazabilidad canónica del repositorio se mantiene en:

`04_Trazabilidad/Matriz_Trazabilidad_Final_PE5_Rubrica.csv`

Dentro de `dataset_zenodo/` se conserva una copia sincronizada de esa misma matriz únicamente como parte del paquete de publicación.

## Protección de datos

No deben incorporarse a esta carpeta consentimientos con firmas, cédulas, teléfonos, rostros, voces, audios o videos identificables. Los materiales sensibles deben permanecer fuera de la publicación abierta y bajo el esquema restringido definido por el proyecto.
