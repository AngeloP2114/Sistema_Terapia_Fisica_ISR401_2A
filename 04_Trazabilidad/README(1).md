# Trazabilidad y priorización

Esta carpeta contiene los artefactos editables de trazabilidad y priorización del proyecto **Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**.

## Archivos

- `matriz_trazabilidad.csv`: 55 relaciones entre objetivos, stakeholders, evidencias, requisitos, casos de uso, historias, criterios, componentes y mockups.
- `priorizacion_moscow_kano.csv`: priorización de los 32 requisitos funcionales mediante MoSCoW, Kano y WSJF.

## Cálculo WSJF

`WSJF = (Valor de negocio + Urgencia + Riesgo) / Esfuerzo`

## Evidencias consideradas

- Entrevista técnica `EV2-ENT-01`.
- Participantes `EV2-PAC-01` a `EV2-PAC-14`.
- Walkthrough `WALK-TEC-01`, `WALK-TEC-02` y `WALK-NTEC-01`.
- Cuestionario `CUEST-01`.
- Documentos organizacionales `DOC-01`, `DOC-02` y `DOC-03`.
