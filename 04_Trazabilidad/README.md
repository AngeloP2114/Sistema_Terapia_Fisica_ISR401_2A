# Trazabilidad y priorización

Esta carpeta contiene los artefactos de trazabilidad y priorización del proyecto SICST.

La trazabilidad permite relacionar leyes, objetivos, stakeholders, evidencias, requisitos, casos de uso, historias de usuario, criterios de aceptación, componentes y mockups.

## Archivos esperados

- matriz_trazabilidad.csv
- priorizacion_moscow_kano.csv

## Matriz de trazabilidad

El archivo `matriz_trazabilidad.csv` debe relacionar:

- Ley
- Artículo
- Objetivo
- Stakeholder
- Evidencia
- Requisito funcional, no funcional o restricción
- Caso de uso
- Historia de usuario
- Criterio de aceptación
- Componente
- Mockup

## Priorización

El archivo `priorizacion_moscow_kano.csv` debe incluir la priorización de requisitos mediante:

- MoSCoW
- Kano
- Valor de negocio
- Urgencia
- Riesgo
- Esfuerzo
- WSJF

## Nota

Los archivos de esta carpeta se completan a partir de las entrevistas, cuestionarios, walkthrough, requisitos y evidencias del trabajo de campo.
