# Trazabilidad y priorización — SICST PE5

Esta carpeta contiene los artefactos finales de trazabilidad y priorización del proyecto **Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**.

## Archivos principales

- `Matriz_Trazabilidad_Final_PE5_Rubrica.csv` — matriz de trazabilidad final utilizada para la evaluación PE5.
- `priorizacion_moscow_kano.csv` — priorización de requisitos mediante técnicas MoSCoW, Kano y criterios complementarios.

## Matriz de trazabilidad final

El archivo canónico de esta carpeta es:

`Matriz_Trazabilidad_Final_PE5_Rubrica.csv`

La matriz contiene **58 trazas documentales** correspondientes a:

- requisitos funcionales;
- requisitos no funcionales generales;
- requisitos específicos de Inteligencia Artificial.

La cadena principal de auditoría utilizada es:

**Fuente → RF/RNF → CU → Clase UML → Estado → BDD → CP**

La matriz permite verificar la relación entre las fuentes de requisitos y los artefactos posteriores del proyecto.

## Cobertura PE5

La línea base final contiene:

- 33 requisitos funcionales;
- 15 requisitos no funcionales generales;
- 10 requisitos no funcionales específicos de IA;
- 58 trazas documentales totales.

## Métricas relacionadas

La trazabilidad se utiliza como respaldo para las métricas de calidad del proyecto, especialmente:

- **M1 — Completitud**
- **M3 — Verificabilidad**
- **M4 — Trazabilidad**
- **M6 — Corrección**

Los archivos detallados de métricas se mantienen en la carpeta correspondiente al cierre PE5.

## Priorización

El archivo:

`priorizacion_moscow_kano.csv`

contiene información de priorización de los requisitos mediante criterios como:

- MoSCoW;
- Kano;
- valor de negocio;
- urgencia;
- riesgo;
- esfuerzo;
- WSJF.

## Línea base

Para la evaluación PE5 debe considerarse como matriz oficial únicamente:

`Matriz_Trazabilidad_Final_PE5_Rubrica.csv`

Los archivos históricos de matrices anteriores no forman parte de la línea base final.
