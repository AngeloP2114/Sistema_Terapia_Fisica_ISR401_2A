# Codificación temática

Esta carpeta contiene la codificación temática de las entrevistas y la curva de saturación del proyecto SICST.

La codificación temática permite relacionar fragmentos de las transcripciones con códigos, categorías y requisitos derivados.

## Archivos esperados

- codificacion_tematica.csv
- curva_saturacion.png
- curva_saturacion.pdf

## Columnas del archivo codificacion_tematica.csv

El archivo debe contener las siguientes columnas:

- Fragmento
- Codigo
- Categoria
- Requisito_derivado
- ID_evidencia
- Analista_codificador

## Convención de nombres

Ejemplos:

- codificacion_tematica.csv
- curva_saturacion.png
- curva_saturacion.pdf
