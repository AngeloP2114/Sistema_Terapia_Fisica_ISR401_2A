# Transcripciones — SICST

Esta carpeta contiene las transcripciones correspondientes a las sesiones de entrevista y walkthrough realizadas durante el trabajo de campo del proyecto SICST.

## Organización

Los archivos se identifican mediante códigos seudonimizados de participante o sesión, evitando publicar nombres personales.

Se distinguen principalmente:

- entrevistas a pacientes o expacientes;
- sesiones walkthrough utilizadas como evidencia complementaria de validación;
- entrevistas de perfiles técnicos cuando corresponda.

## Uso de los datos

Las transcripciones constituyen evidencia cualitativa del proyecto y se utilizan como fuente para:

- codificación temática;
- análisis de necesidades;
- triangulación de hallazgos;
- trazabilidad con requisitos del sistema.

La codificación temática derivada se encuentra en:

`02_Evidencias/Codificacion_Tematica/`

La doble codificación independiente y el cálculo del acuerdo entre codificadores se encuentran en:

`10_Autoria/doble_codificacion/`

## Privacidad

Los archivos publicados utilizan identificadores seudonimizados. No deben incorporarse nombres, números de identificación, teléfonos u otros datos personales de los participantes en esta carpeta pública.
