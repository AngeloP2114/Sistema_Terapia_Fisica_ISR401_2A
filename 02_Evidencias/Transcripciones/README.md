# Transcripciones — SICST

Esta carpeta contiene las transcripciones correspondientes a las sesiones de entrevista y walkthrough realizadas durante el trabajo de campo del proyecto **Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**.

Las transcripciones representan evidencia cualitativa utilizada durante las fases de elicitación de requisitos, análisis del dominio, identificación de necesidades de los usuarios y validación del sistema propuesto.

---

## Organización

Los archivos se identifican mediante códigos seudonimizados de participante o sesión, evitando publicar nombres personales o información que permita identificar directamente a los participantes.

Se distinguen principalmente:

- entrevistas a pacientes o expacientes de terapia física;
- entrevistas a familiares o cuidadores;
- entrevistas a estudiantes y profesionales del área de fisioterapia;
- sesiones walkthrough utilizadas como evidencia complementaria de validación técnica y no técnica.

# Uso de los datos

Las transcripciones constituyen evidencia cualitativa del proyecto y son utilizadas como fuente para:

- codificación temática;
- identificación de necesidades del usuario;
- análisis de problemas actuales del proceso terapéutico;
- definición y validación de requisitos del sistema;
- triangulación de hallazgos;
- trazabilidad entre evidencia obtenida y requisitos del software.
