# Fotos de aplicación del cuestionario

Esta carpeta contiene fotografías que evidencian la aplicación del cuestionario a los participantes del proyecto SICST.

Las imágenes deben mostrar el proceso de respuesta del cuestionario en celular, laptop o computadora, evitando exponer datos personales sensibles.

## Requisitos

- Formato JPG o PNG.
- Fotografía real del participante respondiendo el cuestionario.
- No mostrar datos sensibles completos.
- Asociar cada foto con el código del participante.
