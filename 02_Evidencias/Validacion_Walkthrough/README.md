# Validación walkthrough

Esta carpeta contiene las evidencias de las sesiones de validación walkthrough realizadas con participantes del proyecto SICST.

Cada walkthrough consiste en mostrar el prototipo o MVP del sistema al participante, registrar sus observaciones y firmar un acta de validación.

## Evidencias esperadas

- Video corto de la sesión walkthrough.
- Acta firmada por el participante.
- Observaciones del participante.
- Cambios sugeridos.
- Resultado de validación.
