# Fotografías del entorno

Esta carpeta contiene fotografías del entorno físico relacionado con el levantamiento de información del proyecto SICST.

Las fotografías evidencian el contexto de uso del sistema, el espacio donde se realizaron entrevistas, aplicación de cuestionarios, revisión del prototipo y condiciones físicas relacionadas con terapia o rehabilitación.

## Requisitos

- Formato JPG o PNG.
- Fotografías reales del entorno físico.
- No usar fotos de internet ni imágenes de stock.
- Conservar metadatos EXIF cuando sea posible.
- Usar nombres con fecha y descripción.

## Convención de nombres

Ejemplos:

- 2026-07-26_Entorno_espacio_terapia_01.jpg
- 2026-07-26_Entorno_iluminacion_02.jpg
- 2026-07-26_Entorno_distancia_camara_03.jpg
- 2026-07-26_Entorno_zona_ejercicios_04.jpg
- 2026-07-26_Entorno_aplicacion_cuestionario_05.jpg
- 2026-07-26_Entorno_revision_prototipo_06.jpg
