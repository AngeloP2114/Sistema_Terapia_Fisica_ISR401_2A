# Respuestas del cuestionario

Esta carpeta contiene las respuestas exportadas del cuestionario aplicado a los participantes del proyecto SICST.

Los archivos deben provenir directamente de Google Forms, Microsoft Forms o una herramienta equivalente, conservando las respuestas registradas y la marca temporal.

## Archivos esperados

- Archivo de respuestas en formato XLSX.
- Archivo de respuestas en formato CSV.
- Reporte o captura de gráficos de resultados del cuestionario.

## Convención de nombres

Ejemplos:

- 2026-07-26_Respuestas_Cuestionario_SICST.xlsx
- 2026-07-26_Respuestas_Cuestionario_SICST.csv
- 2026-07-26_Graficos_Cuestionario_SICST.pdf
- 2026-07-26_Captura_Resumen_GoogleForms.png
