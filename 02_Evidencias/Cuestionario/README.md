# Cuestionario de necesidades — SICST

Esta carpeta contiene el instrumento utilizado para recopilar información sobre necesidades, dificultades, privacidad y seguimiento terapéutico dentro del proyecto:

**Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**

El cuestionario fue aplicado como parte de la asignatura **Ingeniería de Requerimientos** y su objetivo es respaldar y validar requisitos del ERS/SRS mediante evidencia empírica.

## Archivo principal

El instrumento completo se encuentra en:

`cuestionario_necesidades_SICST.pdf`

El PDF contiene las preguntas y opciones utilizadas en Google Forms.

## Contenido del cuestionario

El instrumento incluye:

- aceptación voluntaria para participar;
- código anonimizado del participante;
- identificación del perfil del participante;
- preguntas dirigidas a pacientes, ex pacientes, familiares y cuidadores;
- preguntas dirigidas a fisioterapeutas, estudiantes o practicantes;
- dificultades durante los ejercicios domiciliarios;
- necesidad de recordatorios e indicaciones;
- registro de dolor y fatiga;
- seguimiento del progreso terapéutico;
- privacidad y protección de información;
- autorización para uso de cámara o imágenes;
- indicadores y reportes de evolución;
- recomendaciones para mejorar el seguimiento terapéutico.

## Privacidad

El cuestionario no solicita nombres completos como mecanismo de identificación.

Los participantes se identifican mediante códigos, por ejemplo:

`EV2-PAC-01`

Las respuestas públicas no deben incluir nombres, correo electrónico, número de teléfono, dirección IP ni otros identificadores directos.

## Respuestas

Las respuestas exportadas del cuestionario **no se almacenan en esta carpeta**.

Se encuentran en:

- `Cuestionario/` → instrumento aplicado.
- `Respuestas/` → datos obtenidos mediante el instrumento.

## Reproducibilidad

Para revisar el instrumento utilizado en el estudio:

1. Abrir `cuestionario_necesidades_SICST.pdf`.
2. Revisar las preguntas, opciones y ramificaciones por perfil.
3. Consultar las respuestas anonimizadas en `../Respuestas/respuestas_cuestionario_2B.csv`.
4. Contrastar los resultados con los requisitos y la trazabilidad documentados en el ERS/SRS.
