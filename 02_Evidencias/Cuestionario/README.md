# Cuestionario

Esta carpeta contiene las evidencias relacionadas con el cuestionario aplicado a los participantes del proyecto SICST.

Incluye fotografías de aplicación del cuestionario, respuestas exportadas en formato CSV/XLSX y capturas o reportes de resultados generados desde Google Forms.

## Subcarpetas

- `Fotos_Aplicacion/`: fotografías de participantes respondiendo el cuestionario.
- `Respuestas/`: archivos exportados con las respuestas del cuestionario.

## Convención de nombres

Ejemplos:

- 2026-07-26_Cuestionario_Formulario.png
- 2026-07-26_Respuestas_Cuestionario_SICST.xlsx
- 2026-07-26_Respuestas_Cuestionario_SICST.csv
- 2026-07-26_Graficos_Cuestionario_SICST.pdf
