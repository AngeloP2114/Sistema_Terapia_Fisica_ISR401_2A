# Modelado del sistema

Esta carpeta contiene los artefactos de modelado del Sistema Inteligente de Control y Seguimiento de Terapia Física.

Incluye diagramas UML y mockups relacionados con los requisitos funcionales de prioridad Must.

## Subcarpetas

- `Diagramas_UML/`: diagramas de casos de uso, clases, secuencia, actividad, estados, componentes y despliegue.
- `Mockups/`: prototipos o capturas de pantallas del sistema.

## Convención general

Los archivos deben nombrarse con identificadores claros, por ejemplo:

- DUC-01_Diagrama_Casos_Uso.png
- DCL-01_Diagrama_Clases.png
- DSE-01_Secuencia_Login.png
- DAC-01_Actividad_Sesion_Terapia.png
- DES-01_Estados_Tratamiento.png
- DCO-01_Componentes.png
- DDE-01_Despliegue.png
- MU-01_Login.png
- MU-02_Dashboard_Fisioterapeuta.png
