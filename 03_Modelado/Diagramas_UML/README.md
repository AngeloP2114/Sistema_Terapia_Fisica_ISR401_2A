# Diagramas UML

Esta carpeta contiene los diagramas UML del Sistema Inteligente de Control y Seguimiento de Terapia Física.

Los diagramas permiten representar visualmente los casos de uso, clases, procesos, interacciones, estados, componentes y despliegue del sistema.

## Diagramas esperados

- Diagrama de casos de uso.
- Diagrama de clases.
- Diagramas de secuencia.
- Diagramas de actividad.
- Diagrama de estados.
- Diagrama de componentes.
- Diagrama de despliegue.

## Convención de nombres

Ejemplos:

- DUC-01_Diagrama_Casos_Uso.png
- DCL-01_Diagrama_Clases.png
- DSE-01_Secuencia_Iniciar_Sesion.png
- DSE-02_Secuencia_Asignar_Rutina.png
- DSE-03_Secuencia_Registrar_Progreso.png
- DAC-01_Actividad_Sesion_Terapia.png
- DES-01_Estados_Rutina_Terapeutica.png
- DCO-01_Diagrama_Componentes.png
- DDE-01_Diagrama_Despliegue.png

## Formatos recomendados

Cada diagrama debe subirse, si es posible, en:

- PNG
- SVG
- Archivo editable de la herramienta usada
