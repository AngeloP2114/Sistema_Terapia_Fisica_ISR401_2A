# Diagramas del proyecto SICST

Esta carpeta contiene los diagramas utilizados para documentar el modelado y diseño del proyecto SICST.

Incluye diagramas de contexto, dependencia y justificación estratégica, casos de uso, secuencia, actividad, estados, clases, componentes, despliegue y DFD.

Las imágenes exportadas se relacionan con los requisitos y casos de uso documentados en el ERS/SRS y con la matriz de trazabilidad del repositorio.

Cuando exista el archivo fuente editable de un diagrama, debe conservarse junto con su exportación para acreditar su elaboración.
