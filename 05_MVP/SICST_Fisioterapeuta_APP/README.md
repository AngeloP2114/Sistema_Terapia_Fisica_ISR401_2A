# SICST Fisioterapeuta APP

Aplicación web del fisioterapeuta para el Sistema Inteligente de Control y Seguimiento de Terapia Física.

## Objetivo

Permitir que el fisioterapeuta registre pacientes, gestione evaluaciones iniciales, administre ejercicios, asigne rutinas terapéuticas, revise el seguimiento del paciente, consulte alertas, genere reportes y gestione permisos de privacidad.

## Módulos principales

- Dashboard
- Pacientes
- Evaluación inicial
- Catálogo de ejercicios
- Asignación de rutinas
- Seguimiento terapéutico
- Alertas
- Reportes
- Privacidad y consentimientos

## Archivos esperados

- index.html
- css/styles.css
- js/app.js

## Ejecución

1. Abrir la carpeta `SICST_Fisioterapeuta_APP`.
2. Abrir `index.html`.
3. Ejecutar con Live Server o abrir directamente en el navegador.

## Relación con requisitos

Esta aplicación se relaciona con requisitos funcionales de registro de pacientes, evaluación inicial, asignación de rutinas, seguimiento terapéutico, generación de reportes, alertas y gestión de privacidad.
