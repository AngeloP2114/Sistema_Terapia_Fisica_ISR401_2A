# SICST Paciente APP

Aplicación web del paciente para el Sistema Inteligente de Control y Seguimiento de Terapia Física.

## Objetivo

Permitir que el paciente consulte su rutina terapéutica, revise ejercicios guiados, registre dolor y fatiga, visualice su progreso, configure recordatorios y gestione autorizaciones de privacidad.

## Módulos principales

- Inicio
- Mi rutina
- Ejercicio guiado
- Registro de dolor y fatiga
- Mi progreso
- Recordatorios
- Privacidad
- Ayuda

## Archivos esperados

- index.html
- css/styles.css
- js/app.js

## Ejecución

1. Abrir la carpeta `SICST_Paciente_APP`.
2. Abrir `index.html`.
3. Ejecutar con Live Server o abrir directamente en el navegador.

## Relación con requisitos

Esta aplicación se relaciona con requisitos funcionales de consulta de rutinas, visualización de ejercicios, registro de dolor/fatiga, consulta de progreso, recordatorios y consentimiento para uso de cámara.
