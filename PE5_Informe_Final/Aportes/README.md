# Aportes individuales del informe PE5

Esta carpeta organiza las partes del informe final PE5 asociadas a los integrantes que cuentan con un archivo de aporte almacenado en el repositorio.

Los PDF aquí incluidos sirven como apoyo documental. La acreditación definitiva de autoría debe realizarse en `10_Autoria/aporte_individual.md`, vinculando cada aporte con rutas de artefactos y commits reales del historial.
